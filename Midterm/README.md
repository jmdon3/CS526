For problem 1 - Snowfall I wrote my program to calculate how much snow there was in a day based off of the running total that we got from the test files. I did this using a for loop to create a second list that stores the current day's running total less the previous day's. Then I used a second loop, this time while, to add up the next consecutive trio of day's snowfall and comparing it to the total snowfall halved. Calculating the daily amounts simplified the calculation required in my head rather than subtracting the first from the third. Keeping in mind feedback from the homework, the program completes as soon as a yes response is triggered to avoid unnecessary calculations. Each possible combination within the limits of the instructions need to be tested to prove the false case so that return only shows up at the end of the function except for once earlier to account for edge cases where there are fewer than 3 days in the file as instructed.
My program uses standard in to get the snowfall information to be tested and running the program is done in git bash with each test file run from my computer's downloads folder:
py /c/users/jmd.../snow.py < /c/users/jmd.../snowfall_input#.txt
The program for problem 2 - Pandemic that I wrote uses the multiplication repetition to create a state map based on the square size as provided by the input and then a while loop iterating through the rest of the input 2 at a time to get the infected county coordinates and mark them as such. The main function then uses deep copy from the copy library to create a distinct second list so that I have a previous day and current day to work out the spread of the disease. Counties where the disease reaches in subsequent days were identified using 2 nested for loops to iterate through the map. For each county, I then use a series of if statements to first identify counties already infected, then looking at each neighbor and placing the infected ones into a neighbor's list. I then count how many neighbors were stored and if more than 1, then the county should be marked as infected in the current day map. Once the current day map is completed, if statements determine if the spread is finished and if not then a recursion of the function is called to go through the same process with the new map.
This program also uses standard in to get the data and was tested in git bash from my downloads folder. The code was:
py /c/users/jmd.../pandemic.py < /c/users/jmd.../pandemic_input#.txt
Program 3 - Symbol Puzzle Game required the strip function to remove line returns and listing the comma as an argument for the split in order to put the data into a list. The function to determine whether or not the puzzle board given is valid uses a series of nested for loops. The first uses one to pull a row from the board and one inner loop to iterate through the valid symbols list pulled from the file to count how many times each one shows up, ending the program with a message that the board is invalid if there are multiples. The second uses two to iterate through rows and columns to build lists of symbols in a column, using the valid symbols list to ignore periods, checking if the current symbol is in the column list already in case the program can be ended, and then storing the unique symbols in a list otherwise. The final one checks the sub boards for uniqueness of all symbols and I couldn't find a way to avoid 3 nested loops here. The first iterates through sub boards, multiplying the iterated number by the square root of n in order to properly traverse each sub board. Then the inner 2 iterate through rows and columns, using similar logic to the columns loops were periods are ignored, then symbols are checked against a sub board list for duplicates, and the sub board list is updated if the symbol is unique.
As with the other programs, this used standard in and was run with git bash with the following code:
